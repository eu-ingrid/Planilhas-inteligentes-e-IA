# Planilhas-inteligentes-e-IA
 > ℹ️ Repositório criado durante o Bootcamp "CAIXA - IA Generativa com Microsoft Copilot", curso que realizei na plataforma da [DIO](https://dio.me)


## 💻 Objetivo: 

Criar planilha no excel, a qual poderá ser usada para que uma IA gere insights a respeito dos dados. <br>
<a href="https://github.com/eu-ingrid/Planilhas-inteligentes-e-IA/blob/main/output/Planilhas%20com%20IA.xlsx" title="Planilha"> Planilha</a>


## 💻 Tecnologias utilizadas:

- [Mirosoft Excel](https://www.microsoft.com/en/microsoft-365/excel) 
- [ChatGPT](https://chatgpt.com/)


## 🛠️ Execução

- A planilha foi criada seguindo as orientações do curso "Como organizar sua vida Financeira com Planilhas Inteligentes e IA".<br>
<i>Ressalta-se que foi utilizada a versão web do Excel e nem todas as funcionalidades apresentadas no curso estavam disponíveis. Portanto, a planilha gerada não contém todos os elementos ensinados na aula. </i>
- Após finalizada, a planilha foi arrastada para a área de trabalho do ChatGPT, acompanhada do prompt:<br>
"Com base nesta tabela de dados gere alguns insights sobre os gastos. "
- [Clique para ver o chat](https://github.com/eu-ingrid/Planilhas-inteligentes-e-IA/blob/main/output/ChatGPT.pdf)
